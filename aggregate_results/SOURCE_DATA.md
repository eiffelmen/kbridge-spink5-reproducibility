| MCP-counter | B-lineage and fibroblast marker definitions for the bulk composition analysis | [Pinned signature definitions](https://raw.githubusercontent.com/ebecht/MCPcounter/6b85a671cfa8385798cea6147b6613a172e47ff5/Signatures/genes.txt) · [Becht et al.](https://doi.org/10.1186/s13059-016-1070-5) |

The analyses use public processed expression and source annotations. No third-party input matrices, metadata workbooks, annotation files or signature tables are redistributed here. Aggregate results from the TCGA-HNSC analysis are based on data generated by the TCGA Research Network.

For traceability, each retained table lists its source member from Supplementary Data 1. That source file had SHA-256 3b3f267f197389ef9a305e5914359152d6ffcfd640e5462f5101994356056890. It is unnecessary for reproduction from the primary data. The only transformed outputs are the pooled tonsil summary, which retains only pooled results and drops specimen identifiers, and the composition-correlation table, which replaces signature symbols with marker counts.
