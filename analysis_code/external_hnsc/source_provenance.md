# Data provenance

Access date: 25 September 2026.

- Study: [GEO GSE65858](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE65858), a deposited HNSCC microarray cohort on GPL10558. GEO reports 270 arrays after quality control and removal of duplicates/non-HNSCC materials. The native sample metadata further records Primary (253), Secondary (14), and Relapse (3), so the association analysis distinguishes these categories.
- Processed expression/phenotype: [official series matrix](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE65nnn/GSE65858/matrix/GSE65858_series_matrix.txt.gz). Expected compressed bytes: 21,329,581. Native matrix has 31,330 retained probes and 270 sample columns. Source processing includes log2 transformation, robust spline normalization (RSN), ComBat batch adjustment, expression/quality filtering and removal of duplicate measurements. Existing transformed values are retained.
- Probe mapping: [official GPL10558 platform](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL10558), whose supplied metadata identifies the manufacturer annotation updated 11 October 2012 to HumanHT-12_V4_0_R2_15002873_B.txt. The [GEO-deposited manufacturer file](https://ftp.ncbi.nlm.nih.gov/geo/platforms/GPL10nnn/GPL10558/suppl/GPL10558_HumanHT-12_V4_0_R2_15002873_B.txt.gz) has expected compressed size 13,721,073 bytes. Mapping uses exact `Symbol=SPINK5`, `Probe_Id`; no survival-based mapping decision.
- Publication: Wichmann G, Rosolowski M, Krohn K, et al.; Leipzig Head and Neck Group. The role of HPV RNA transcription, immune response-related gene expression and disruptive TP53 mutations in diagnostic and prognostic profiling of head and neck cancer. International Journal of Cancer 137(12):2846–2857 (2015). [DOI](https://doi.org/10.1002/ijc.29649), [PubMed PMID 26095926](https://pubmed.ncbi.nlm.nih.gov/26095926/). Citation metadata verified on primary publisher and PubMed records.

The endpoint uses native GEO `os` and `os_event` (TRUE treated as death, FALSE censored). The matrix does not explicitly label the time unit. The script keeps time in its recorded scale and reports no fixed-time absolute survival probabilities. Continuous Cox coefficients and rank-based proportional-hazards tests are invariant to a common change in the time unit. Units are therefore not silently relabelled as days.

Downloads use official public URLs; no local patient data were uploaded. The platform family SOFT request was stopped by a 100-MB size cap before data were downloaded. Several proxy connections failed; direct byte-range requests were used for the two compressed files and their complete lengths and gzip integrity were checked. Partial exploratory download files are not analysis inputs. The successful data inputs total approximately 35 MB compressed, below the 300-MB cap.
