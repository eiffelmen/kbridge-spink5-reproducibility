# K-BRIDGE and SPINK5 in head and neck cancer: analysis code and aggregate results

Version 1.0.0

Analysis code, public-input preparation and aggregate numerical results supporting the K-BRIDGE B-cell state evaluations and SPINK5 survival analyses in head and neck squamous cell carcinoma. The implementation documents the public GEO and UCSC Xena inputs and the commands to reproduce the analysis. The accompanying tables report aggregate discrimination, survival and sensitivity results and the fixed gene-to-program map. Participant, specimen and cell-level inputs remain at their respective public data sources.

- [Aggregate results and provenance](aggregate_results/README.md)
